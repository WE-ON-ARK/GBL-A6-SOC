# 재난 5분 전, 옵티마이저

AI 에이전트와 함께하는 확률적 최적화 챌린지 웹앱입니다. 참가자는 예산 100 안에서 전략 카드 3장을 고르고 세 번의 타임루프를 수행하며 도시 대피망을 개선합니다.

## 주요 기능

- 전략 카드 3장 선택과 예산 제약
- 루프별 대피율, 변동성, 목표 달성 확률, 피해액, 지역 격차 시뮬레이션
- 최소 절단과 파레토 상충관계 시각화
- 로컬 학습 코치와 외부 LLM BYOK 연결
- OpenAI, Anthropic, Google Gemini, OpenAI 호환 API 지원
- API 키는 서버에 저장하지 않고 현재 탭 세션에서만 사용
- 마스터 프롬프트, 유저 노트, OOC 지침으로 구성된 스토리 프롬프트 스택
- 대화창의 STORY/OOC 입력 모드 분리

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 외부 모델은 우측 상단의 **모델 연결**에서 공급자, 모델 ID, API 키를 입력해 사용할 수 있습니다.
